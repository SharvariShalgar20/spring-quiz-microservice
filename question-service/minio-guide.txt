Run MinIO Locally + Create a Bucket

1. Run MinIO via Docker

docker run -d --name minio \
  -p 9000:9000 \
  -p 9001:9001 \
  -e MINIO_ROOT_USER=minio***** \
  -e MINIO_ROOT_PASSWORD=minio******** \
  -v minio-data:/data \
  minio/minio:RELEASE.2025-09-07T16-13-09Z-cpuv1 server /data --console-address ":9001"


2. Confirm it's running

docker ps

3. Open the web console

http://localhost:9001

Login with your credential(same as you set while running container)

4. Create a bucket

In the console, click Buckets → Create Bucket → name it:
question-images
click Create.
